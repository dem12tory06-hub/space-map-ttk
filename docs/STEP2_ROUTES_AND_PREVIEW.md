# Шаг 2. Автоматический маршрут и локальный просмотр

Этот архив содержит код конструктора, экрана посетителя и редактора проходов. На GitHub и Aeza он ещё не опубликован.

## Посмотреть на Windows без установки Node.js

1. Распакуйте новый архив **в отдельную папку**. Внутри неё должны быть `preview-windows.cmd`, `preview-local.py`, `index.html`, каталоги `src/` и `server/`.
2. Дважды щёлкните по `preview-windows.cmd`. Если Windows попросит подтверждение запуска файла из интернета, проверьте, что это файл из распакованного проекта, и запустите его. Должно открыться окно командной строки с адресом `http://127.0.0.1:8765/constructor`.
3. Откройте этот адрес в браузере компьютера. Введите любое название площадки; ключ организатора для **этого локального предпросмотра** — `preview`.
4. На вкладке «Места» поставьте «Вход» и «Регистрацию» возле входа в рабочую область. Если нужен Wi-Fi, добавьте точку «Wi-Fi» и заполните её отдельные поля «Логин (название сети)» и «Пароль»: посетитель увидит их в карточке. Во вкладке «Объекты» нарисуйте большую «Рабочую зону»; отдельные столы не нужны. Поставьте стенд, сцену и при необходимости стену.
5. Во вкладке «Маршрут» выберите «Вход» и «Стенд», нажмите «Проверить путь». Синий путь автоматически обойдёт стену и сцену; через рабочую зону проходить можно. Организатор не рисует маршруты для каждой пары мест.
6. Необязательно: если нужно направить посетителя по конкретному проходу, выберите «Изгибы», добавьте предпочтительный участок и при необходимости его изгибы. Сеть участков по умолчанию скрыта, чтобы линии не накладывались. «Показать сеть проходов» включает её полупрозрачным слоем. Кнопка «Показать» выделяет один участок; «Изменить» позволяет перетаскивать изгибы, менять X/Y или удалять их. Закончите кнопками «Сохранить участок» и «Сохранить».
7. Нажмите «Ссылка на карту» и откройте адрес в другой вкладке **того же компьютера**. Проверьте путь между двумя местами, затем кнопками «Старт на плане» и «Финиш на плане» выберите любые свободные точки. Сцена доступна как цель, но путь заканчивается рядом с её краем. Стена и сцена перекрывают проход; зона проходима.

**Сдвиг карты:** нажмите «+» для увеличения, выберите инструмент «Сдвиг карты», удерживайте кнопку мыши на плане и перетаскивайте. Он меняет только то, какую часть увеличенного плана видно на экране; координаты зон не меняются. Стрелки рядом с масштабом сдвигают вид на фиксированный шаг. «Показать весь план» возвращает начальный масштаб и положение.

Предпросмотр работает через отдельный маленький сервер на Python. Он запускает **тот же HTML/CSS/JavaScript интерфейса**, но хранит тестовую площадку только в памяти. После закрытия чёрного окна данные пропадут. Не вводите в предпросмотр настоящий ключ Aeza; `preview` не является рабочим ключом. Загрузка подложки и фотографий здесь не поддерживается. Проверку настоящего Node.js API проводит участник 1 на сервере.

Если `preview-windows.cmd` сообщает, что `py` и `python` не найдены, сообщите текст ошибки. Если порт 8765 уже занят, закройте другое окно предпросмотра и запустите файл снова.

## Передача участнику 1

Передайте ему **последний архив целиком**, не архив первого шага. Его нужно слить с актуальной версией в GitHub; простая замена рабочей папки Aeza может удалить несохранённые изменения и обойти проверку. Каталог `DATA_DIR` с реальными площадками и файлами должен остаться вне заменяемого кода. После объединения: `npm test`, запуск в отдельной среде, проверка маршрута на телефоне, затем обновление службы Aeza. Файлы `preview-local.py` и `preview-windows.cmd` для Aeza не нужны.
