# Шаг 3 — панорамы внутри конструктора

Верхние вкладки конструктора расположены по две в ряд: «Объекты», «Места», «Маршрут», «Панорамы». Во вкладке «Панорамы» организатор ставит отдельную точку на плане. Справа у неё есть название, статус изображения, «Снять и собрать кадры» и, после склейки, «Посмотреть панораму». Кнопка съёмки сначала сохраняет карту, затем открывает страницу с выбранной точкой.

Готовый JPEG записывается под ID именно этой точки в `floors[0].panoramaPoints`. Карта посетителя показывает бирюзовый значок; из его карточки открывается готовый обзор. Старый способ прикрепления панорамы к обычному месту остаётся совместимым.

## Проверить на Windows без Node.js

1. Распакуйте ZIP в новую папку. В папке `space-map-ttk` запустите `preview-windows.cmd`. Он откроет локальную карту на порту 8765. Оставьте окно открытым.
2. Там же запустите `start-panorama-worker-windows.cmd`. При первом запуске он создаст `.venv` и установит Flask, NumPy и OpenCV. Для установки нужен интернет. Оставьте и это окно открытым.
3. Откройте `http://127.0.0.1:8765/constructor?venue=6e03d42c-872f-4f2b-8b20-42b0b1ecaefc`, введите ключ `preview`.
4. Нажмите верхнюю вкладку «Панорамы». На карте уже есть точки у входа и у партнёров. Можно выбрать существующую или нажать «Поставить панораму» и поставить новую. Переименуйте её в свойствах справа.
5. Нажмите «Снять и собрать кадры». На странице съёмки точка выбрана сразу. Введите ключ `preview`, добавьте 2–24 снимка с одной неподвижной позиции, проверьте порядок и нажмите «Собрать панораму».
6. Вернитесь по ссылке «К конструктору», вновь введите `preview`, выберите точку и нажмите «Посмотреть панораму». Также проверьте `http://127.0.0.1:8765/map/6e03d42c-872f-4f2b-8b20-42b0b1ecaefc`: бирюзовая точка открывает обзор из карточки посетителя.

Оба адреса `127.0.0.1` работают только на этом компьютере. Для съёмки на Samsung A54 пока перенесите кадры на компьютер. После слияния с сервером Aeza организатор сможет открыть страницу съёмки по HTTPS с телефона.

## Участнику 1 при слиянии с актуальным Git

В этом ZIP рабочая копия проекта, а не команда заменить папку сайта. Сверить `src/constructor/`, `server/app.js`, `server/panorama-integration.js`, `server/panorama-capture.html`, `server/panorama-worker.py`, `src/panorama/`, `src/visitor/` и формат `panoramaPoints` с текущим Git. Node принимает серию только с ключом организатора и актуальной ревизией, передаёт снимки Python worker по `STITCH_SERVICE_URL` и сохраняет JPEG в общем `DATA_DIR/panoramas`. Python worker слушает только `127.0.0.1:5000`. Данные площадок и `DATA_DIR` на Aeza не заменять содержимым ZIP.

Автоматические тесты проверяют обмен и чтение готового файла после сохранения. Реальную новую склейку OpenCV в этой среде не запускали: она требует серию исходных кадров и установленные Flask/OpenCV. На локальном Windows-предпросмотре проверьте её кадрами вашего мероприятия до публикации.
