# Склейка панорам

Это исходники локальной программы из `TTK_Panorama`: `server.py` и `panorama-capture.html`.
Снимки, готовые панорамы и `.venv` не входят в проект.

Для запуска нужен Python с пакетами из `requirements.txt`:

```powershell
python -m pip install -r tools/panorama-stitch/requirements.txt
python tools/panorama-stitch/server.py
```

Откройте `http://127.0.0.1:5000`, выберите вход или зону партнёров и склейте серию кадров.
Скачайте полученный JPEG. В конструкторе площадки поставьте «Точку панорамы», дайте ей имя,
укажите горизонтальный охват и выберите этот JPEG. После успешной загрузки изображение
хранится в `DATA_DIR/panoramas/<venueId>/`, а ссылка на него — в той же площадке.

Склейка пока работает локально. Для Aeza потребуется отдельно установить Python/OpenCV
и безопасно подключить сервис съёмки; копирование этого каталога само по себе его не запускает.
Частичную панораму следует отметить фактическим горизонтальным охватом, а не 360°.
